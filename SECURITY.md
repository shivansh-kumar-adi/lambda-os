# Security

## Scope

This repository holds documentation only, so it has no runtime attack surface. It contains no secrets, keys or environment values, and none should ever be added.

## Reporting

If you find any of the following, please report it privately through the contact details on [shivanshonline.in](https://shivanshonline.in) rather than opening a public issue:

- a secret, token or credential accidentally included here,
- personal data or a local machine path that should not be public,
- a documented claim that overstates security.

You can expect an acknowledgement and a correction as soon as practical. No response time is promised.

## Claims

This showcase does not claim that ΛOS is sandboxed, hardened, certified or enterprise-ready, and no security audit has been performed. See [AI security model](docs/06-ai-security-model.md).
